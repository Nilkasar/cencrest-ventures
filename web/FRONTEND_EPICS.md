# BeBest Frontend — Epic Plan

## Stack
- Next.js 15 (App Router, TypeScript)
- Tailwind CSS + shadcn/ui (component base)
- Framer Motion (React transitions, layout animations)
- GSAP (page transitions, scroll-driven, counters)
- React Three Fiber (3D canvas — source field visualization)
- TanStack Query (data fetching + cache)
- Zustand (client state)
- Recharts + D3 (animated data viz)
- Zod (form validation)
- React Hook Form
